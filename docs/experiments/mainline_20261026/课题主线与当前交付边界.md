# 课题主线与当前交付边界

本页记录此前已经讨论确定的研究边界，供后续修改课题文档使用，不表示后续实验已经执行。

1. **主线是任务驱动的感知通信决策。**依据具体下游任务和当前状态，决定使用哪些设备、哪些模态、何种传输层级与数据精度/压缩比例、何时发送以及如何分配信道资源。模型升级和融合模块为这一主线提供可信的输入与可比较的任务结果。
2. **近期主任务保持目标导向视觉语言导航。**根据类别和颜色等语言指令寻找、确认并安全接近指定车辆。可选扩展直接研究局部交通拥塞趋势预警，不必经过占道巡检这一中间任务；预警应另建交通状态、历史窗口、预测时域和标签/评价协议。
3. **真实异质多模态仍需继续建设。**当前RGB与深度用于视觉识别和几何支持，本轮验收不能代替图像、真实LiDAR点云等异质模态的接入及贡献验证。文字用于任务描述和约束；音频等是否加入依据任务需要决定，无须为了凑模态而全部接入。
4. **三个层级是通信表示层级。**原始数据级、特征级、目标语义级是发送的数据形式，不是三种模态。默认同一设备、同一模态、同一次观测选择“不发送”或一种表示层级；不同设备、模态可以选择不同层级。层级选择之外，还需明确各层级的数据精度与压缩参数。
5. **接收端融合方案仍待选型。**处理中心及链路拓扑未最终确定；可优先评估复用UGV接收端。“特征融合＋目标状态融合”仅为暂定候选，要与统一目标状态、BEV/查询等方案比较适配成本和小样本效果，再决定主方案，不能在文档中写成已证明最优的最终架构。
6. **后续顺序不改变。**完成当前感知及必要修复验收，接入点云并验证设备/模态贡献；确定中心与融合方式；实现三层真实编码、传输、解码和统一任务接口，再冻结正式基线；随后研究目标导向信息价值与动态资源分配，先做启发式/数学优化及固定周期、固定层级、置信度策略对照；强化学习与拥塞预警按需要扩展。

本轮只做修复与必要的定向验证，完整新旧36对/72回合已按用户要求延期。识别权重保持冻结，不能将共同安全、导航、停车或评价修复的收益全部归因于识别网络。原场景未完成回合须继续如实保留，不能以在线目标验收通过推导全部场景任务都能完成。
