# 2026-10-26 已完成主线同步

本发布以R10 v5冻结的图像识别与闭环修复为主体，增加后续已验证的目标/背景真值访问防护和严格独立S3判定。整理时移除了旁路原生LiDAR记录入口；没有接入LiDAR模型、UAV点云功能或交通拥塞试验。

## 已有实验结论

- 已采集并独立评价22个定向验证回合，保留失败与重试台账。
- 8个正例找到正确目标并满足包围框停稳协议；2个无目标负例未发送目标消息；4个安全用例有独立物理审核支持。
- 原问题场景E3、W2、W3、F3完成，E2、F1未完成；N3旧/新对照的严格轨迹配对未通过。
- 18个非安全专用任务记录经严格S3重新审核，原12次成功仍为12次，没有事后增加成功数。
- R10原代码检查为242项；本发布加上严格成功与真值防护测试后为269项。本次同步只运行代码和配置检查，没有重新启动仿真或重跑72回合。

这些是受控同地图的开发/回归证据，不能解释为独立跨地图泛化、完整新旧模型提升统计或全部问题已解决。灰色/黑色UAV候选误选等弱项见 [感知指标](感知指标与依据.md)。

## 成功判据与术语更正

原报告“真实车体间隙”使用CARLA API actor包围框计算，统一限定为 **包围框水平间距**，不是精确车身网格距离。

严格S3需要正确目标实例、S1/S2、完整连续2秒/至少41个物理记录、至少6次独立新鲜观测、车速≤0.3m/s、在线间距4–7米、评价包围框间距3–8米、可行驶足迹与全回合无碰撞。缺帧、重复、过期观测、错误实例或缺失证据均不能判成功。路口短暂停稳按已确认规则允许并单独标注。

评价器可事后使用目标实例与几何真值。在线控制只使用任务、传感器、自身状态、地图与标定；对象真值的初始化和日志记录不属于在线感知输入。

## 代码与复现材料

22份配置位于 configs/releases/mainline_20261026/，来自实际回合的resolved_config。场景、路线、种子、时限与业务阈值保留；安装、权重和输出路径通过配置准备器改写。整理检查见 publication_checks.json，历史源指纹见 r10_source_and_model_manifest.json。

模型仍使用冻结YOLOE检测/分割、辅助车辆候选、深度处理和ResNet18车型/颜色分支。颜色判断不是全部由YOLOE完成。权重保留本地，登记5个模型资产的名称与哈希；校准发布JSON作为说明材料保留。

发布结构变化包括源码汇集、剥离旁路点云记录、路径/配置准备及文档。不能把发布目录的新源码哈希说成旧22回合采集时逐字节相同的版本，也没有宣称此次同步新增了完整闭环实验。
