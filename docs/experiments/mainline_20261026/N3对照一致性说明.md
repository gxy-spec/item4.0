# N3 对照检查：哪些已经修正，哪些仍未通过

本次两回合均未根据目标消息生成路线，且全程无碰撞；但**严格的逐轨迹配对审核未通过**。不能把同种子、同起点称为两次完全相同的闭环过程，也不能把后续轨迹差异归为目标识别模型带来的收益。

|检查项|实测结果|结论|
|---|---|---|
|初始位置、初始朝向|对应角色一致|通过|
|固定仿真时间步|相对时间逐点一致|通过|
|安全检测采样帧|相对帧序列完全相同|通过|
|目标消息引起的路线|新旧两回合均为 0 条|通过|
|UGV 全程轨迹差|最大约 30.62 米；预设上限 0.10 米|未通过|
|背景行人轨迹差|其中一人最大约 1.10 米；预设上限 0.50 米|未通过|

**差异是如何开始的：**在约 7.35 秒，两次安全链路先产生了不同的行人等待决定；约 7.45 秒开始出现大于 1 毫米的 UGV 平面位置差。两名行人的位置则分别到约 34.85 秒、50.15 秒才出现大于 1 毫米的差异。因此，不能把最初的 UGV 差异直接归咎于行人位置不一致。

对分歧前的 0、1、5、7、7.25 秒已存储输入进行核对：相机位姿一致，前三个时点深度编码逐像素一致，但 RGB 已有微小不同。7.25 秒的平均通道差为约 0.061/255，约 4.52% 的像素至少一个通道不同。微小图像差异与检测、跟踪和安全阈值共同影响决策，是当前证据支持的解释；尚未唯一确定是渲染、动画还是其他图像产生环节造成差异。

**补充的同输入复验：**将同一套录制 RGB-D 和自身位姿依次送入两份独立初始化的安全检测、跟踪及危险分类实例。33 个已保存帧的检测结果和危险决定逐帧相同，公共安全源码的采集快照哈希也一致。该复验使用 CPU、已保存的 4Hz 输入；它能说明公共组件在这些相同输入下可复现，不能替代 20Hz 完整在线过程，也不能将上述闭环配对失败改判为成功。

当前处理是保留原严格容差、失败结论和完整数据；本轮不据此进行新旧模型闭环优劣归因。后续完整模型对比应同时提供同帧感知审计和多种子闭环统计；如需逐路径严格配对，还需单独固定并验证相机渲染、动态背景与完整传感器输入的复现机制。不能依靠挑选一次看起来相同的重跑来解决。
