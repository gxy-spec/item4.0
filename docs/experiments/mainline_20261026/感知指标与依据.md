# 感知识别结果：两种证据分开看

本轮没有重新训练或更换识别模型。当前前端为YOLOE主检测/分割、辅助车辆提议及深度框补全，车型和颜色由已冻结的ResNet18属性分支判断。HSV证据仍可记录供诊断，当前升级模型的最终颜色匹配使用学习到的颜色概率和冻结阈值。
