# 本轮任务成功怎样判断

最终任务成功必须同时找到正确目标并安全接近，不能只凭检测框、收到消息、走完路线或运行器显示 PASS。

|阶段|本轮判据|
|---|---|
|S1 正确可靠发现|目标类别和颜色符合指令；候选已满足时序确认、框最短边至少16像素；最近5次观测中至少3次在1秒内对应同一正确目标；离线核对传感器定位点到该目标车体投影的外部距离不超过1米。UAV、UGV分别记账，任一设备达到即可。|
|S2 正确地面确认|UGV近距观测：表面水平距离不超过20米、框最短边至少24像素，类别/颜色与指令匹配、测距有效且与已接收目标关联；最近5次中至少3次在1秒内稳定匹配。是否确认的是正确实例，由离线审计另外核对。|
|S3 找到并安全接近|已经正确地面确认；在线估计车体净距保持在4–7米，车速不超过0.3米/秒，连续停稳至少2秒且至少6次新观测、相邻有效观测间隔不超过0.5秒；离线独立核验该保持段真实车体净距始终为3–8米、车体在可行驶区域内，并且全回合无碰撞。|

“车体净距”是两车水平投影外形之间的最小间隙。原来的参考点距离单独保留，不能与净距混算，也不能把历史“参考点3–7米未到达”直接改成“旧指标通过”。车长、朝向和接近方向会改变参考点距离，因此它不适合统一代替安全接近间隙。

按已确认的任务要求，允许在路口连接区短暂停稳完成确认，并单独标记路口位置；这不是现实道路合法停车认证。

已经用语义确认过的目标，可在0.5秒新鲜度及严格框重叠、空间关联条件下继续几何跟踪。未知类别/颜色仍按原始观测记录，不能冒充又一次新的正确属性识别。

远处候选允许先触发核验路线，记作S0；它不等于S1可靠发现，更不等于S2或S3。回放中金色与绿色分别说明这两类规划。所有真值只用于采集后的身份、距离及物理审核，在线规划使用已收到的传感器点、自身状态和道路地图。

本轮阈值是具体仿真实验的工程验收协议，不宣称是目标检测领域通用标准。完整数值、逐观测距离和逐仿真帧停车证据见交付索引。
