# CI-E2 UAV目标候选基线

## 目的

从UAV自身的同步RGB、米制深度和相机位姿中产生车辆候选，完成红色属性判断、三维位置估计和3/5帧时间确认，为后续目标选择与空地消息传输提供感知接口。

## 数据边界

- 感知输入：UAV RGB、同帧深度、相机外参和内参。
- 感知输出：二维框、通用车辆类别、颜色、深度、CARLA世界坐标、置信度、时间确认状态。
- CARLA actor truth：不进入感知链路，只在全部推理完成后计算可见性、召回率和定位误差。

## 方法

1. YOLO26x COCO预训练模型产生 `car/motorcycle/bus/truck` 通用候选。
2. 语言指令给定的红色属性用于HSV/Lab风格的像素属性判断，并以红色连通区域补充极小俯视目标；补充候选必须同时满足观测得到的车辆足迹与离地高度约束。
3. 在框中心区域取稳健深度中位数，根据相机内参反投影，再由传感器位姿转换至CARLA世界坐标。
4. 世界坐标5米关联半径内，最近5帧至少命中3帧才标记为稳定候选。

这一阶段只要求“目标进入候选集”，不把COCO通用类别误称为精确的厢式货车识别。`van`子类识别将在后续目标选择阶段通过专用分类器或微调模型补充。
